# 抓取策略

## 安全边界

- 通过 CDP 把 Playwright 附着到已经运行的 Chromium。
- 只抓取目标同源页面。
- 仅通过普通链接和 GET 导航发现页面。
- 收集 selector 时不提交表单、不点击控件；只允许 hover 可见导航入口以发现
  动态子菜单链接。
- 跳过退出、删除、移除、结账等可能改变状态的路由。
- 每次运行都限制页面数和抓取深度。

## 必须保存的证据

每个成功抓取的页面都保存：

- URL、标题、各级标题和可见可操作元素
- 主 locator、备用 locator 及其唯一性计数
- 元素边界框和附近的语义上下文
- 一张原始截图和一张带元素编号的标注截图

每完成一个页面便更新 `manifest.json`，确保后续运行可以安全恢复。

## 任务驱动

- 用完整 `coverage-corpus` 决定工作流库存；用 `focus-tasks` 调整本轮抓取优先级。
  重点任务缺少某类工作流时，不得从 router 删除该工作流。
- 优先读取真实任务语料，统计任务类型并提取常见起始 URL。
- 把任务集视为可选先验，不作为陌生网站生成的前置条件。
- 任务入口比 DOM 链接优先，但仍受同源、安全路由、页面数和深度限制。
- 任务入口默认最多占页面预算的三分之一，其余预算用于 DOM 路由发现。
- 按任务意图归入少量工作流；无法归类的任务必须显式进入“未归类任务”。
- 没有任务集时，从页面证据激活导航、搜索、读取、账户表单和修改提交等通用工作流。
- 只从已抓取页面提取 locator。缺少证据时标记覆盖缺口，不臆造 selector。
- 任务原文不写入运行时工作流；任务集只决定抓取种子、工作流激活顺序和覆盖统计。
  这样避免任务泄漏，也减少每轮 prompt 体量。
- 不读取 evaluator 期望答案。分类路径提示只能由任务意图与已抓取同源链接匹配
  产生，到达页面后仍须核验标题、URL 或面包屑。

## Context Model

- Context Model 是可选输入，不是陌生网站生成 handbook 的前置条件。
- 只有经审核的正式 `business-core/` 和 `platform-core/bindings/` 可以进入
  handbook；原始 Trace 仍留在证据层。
- 业务对象、能力与条件用于防止选错记录或计算口径；页面状态、动作和 selector
  用于防止点错控件或丢失对象身份。
- 只把当前工作流相关的少量模型事实写入该工作流。全量模型不进入运行时 prompt。
- 如果模型只有对象定义、没有页面状态或动作证据，不得把 selector 覆盖标记为完成。

## 渐进式加载

生成的站点 skill 按以下层级组织：

1. `SKILL.md`：只保留路由和加载规则。
2. `references/handbook.md`：小型工作流索引。
3. `references/workflows/*.md`：单类任务的步骤和少量 locator。
4. `references/context-model.md`：可选的模型范围索引；正常执行无需加载。
5. `snapshots/pages/*.json`：工作流失败后的单页证据。
6. `snapshots/selectors.json`：最后才按关键词检索的全量后备。

不得要求 agent 在任务开始时整体读取全量 selector 或所有工作流。

用于 benchmark 注入时，再生成两层路由：

1. 每个网站的 `router.json` 先用 `site_keys` 和 origin 限定网站，再选择一个窄
   `runtime-skills/*/SKILL.md`。
2. 输出根目录的 `webarena-router.json` 汇总各网站路由。新增网站时增加独立站点
   skill，不把站点 selector 混入公共 router。

运行时 skill 只保留当前策略、成功判据、少量已验证结构和任务驱动路径提示。
截图、全量 selector、任务样例和调试日志不得进入注入文本。

商品列表存在稳定卡片结构时，运行时 skill 额外生成一段单次 DOM 读取模板，只
返回页面身份、总数文本、`name/price/url` 和 Next。模板不包含任务答案；它把
站点 selector 编译成短执行路径，并要求按页面身份去重。

## 迭代规则

仅针对任务语料、页面证据或真实浏览器任务中出现的问题修改生成器。优先选择能
同时改善多个工作流的一条小规则。生成阶段只验证结构、体量和 locator；agent
正确率、token 与步骤数应在外部 benchmark 中验证。

生成候选前必须对完整覆盖语料运行 router 审计。固定失败集只用于学习，不得替代
历史成功题回放或全量晋级测试。
